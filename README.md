# BETNOVA

**A New World of Sports.**

BETNOVA is an independent, mobile-first sports platform prototype built with React, TypeScript and Vite.

## Current status

This repository currently contains the first responsive interface prototype:
- Bright ivory, emerald and turquoise visual identity
- Responsive sports discovery layout
- Illustrative fixture cards and sample prices
- Local demo bet-slip interactions only
- Responsible-play and safety-oriented interface cues

**Important:** This is a front-end prototype. Fixtures and prices are illustrative, and no real bets, deposits, withdrawals, wallet balances, or payments are processed.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Architecture roadmap

1. UI foundation and responsive experience
2. Independent Supabase project and authentication
3. Verified sports data provider integration
4. Market catalogue and bet-slip validation
5. Ledger-based wallet architecture and payment integrations
6. Administration, security controls, audit logs and testing

Do not add secrets, service-role keys, payment credentials, or private API keys to this repository.
